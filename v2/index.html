A Bancada Cartográfica: Guia de Operação

CONTROLOS DE TECLADO
  • ↑ ↓ ← → : Move a mira cartográfica pela matriz.
  • ENTER : Abre o nó ativo na Bancada de Dissecação sem tapar o mapa.
  • ESC : Recolhe a bancada e restaura o mapa a 100%.
  • C : Tranca/desafixa nó para comparação lado a lado.
  • L : Ativa/desativa a camada de linhagem histórica (linhas SVG).
  • H : Abre/fecha este manual de atalhos.
MIRA ÓTICA & BANCADA SPLIT-BENCH

A Versão 2 substitui o padrão modal tradicional por uma bancada de trabalho contínua inspirada no design suíço. Ao abrir um caso de estudo, a matriz reduz-se a 38% da janela para funcionar como minimapa ótico de coordenadas, permitindo saltar instantaneamente entre qualquer outro nó mantendo a leitura aberta no plano direito.
